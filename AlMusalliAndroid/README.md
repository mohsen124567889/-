# المُصلّي AlMusalli — Android

تطبيق Android عربي RTL باسم المُصلّي، مستقل عن مشروع رِفاء، ولا يستخدم Firebase.

## بنية المشروع
- `app/`: تطبيق Android مبني على Java وWebView محلي.
- `app/src/main/assets/index.html`: واجهة التطبيق والوظائف اليومية.
- `MainActivity.java`: جسر Android وطلب الأذونات.
- `AlarmScheduler.java` و`PrayerAlarmReceiver.java`: جدولة تنبيهات الصلاة الدقيقة وإظهار إشعار/نشاط ملء الشاشة.
- `BootReceiver.java`: إعادة جدولة التنبيهات بعد إعادة تشغيل الجهاز.
- `.github/workflows/build-apk.yml`: بناء APK تلقائياً عبر GitHub Actions.

## البناء
من هذا المجلد:
```bash
gradle assembleDebug
```
الناتج:
`app/build/outputs/apk/debug/app-debug.apk`

أو شغّل Workflow باسم **Build AlMusalli APK** من تبويب Actions، ثم نزّل Artifact باسم `AlMusalli-debug-apk`.

## المزايا الحالية
- مواقيت الصلاة من AlAdhan API حسب المدينة المختارة أو إحداثيات GPS بإذن المستخدم.
- إعدادات حساب متعددة، والمدينة الافتراضية مكة المكرمة.
- جدولة تنبيهات Android من خلال AlarmManager، مع إشعار عالي الأهمية ومحاولة عرض شاشة كاملة، واستعادة بعد إعادة التشغيل.
- قراءة سور القرآن بالنص العثماني من AlQuran Cloud API.
- مجموعات أذكار صباح ومساء وأذكار بعد الصلاة.
- مسبحة تحفظ العدد في تخزين المتصفح المحلي.
- تاريخ هجري أم القرى من Intl في الجهاز.
- إعدادات محلية محفوظة على الجهاز.

## ملاحظات مهمة
- يلزم اتصال إنترنت لجلب مواقيت الصلاة ونص القرآن أول مرة؛ لا توجد قاعدة بيانات سحابية خاصة بالتطبيق.
- لا يتم تضمين ملفات صوت أذان؛ الإشعار يعتمد على صوت الإشعارات الافتراضي الذي يحدده Android.
- Android 12+ يتطلب إذن المنبهات الدقيقة، وAndroid 13+ يتطلب إذن الإشعارات. Android 14+ قد يقيّد full-screen intent وفق إعدادات النظام. يجب على المستخدم السماح بها من إعدادات الجهاز.
- بعض الشركات المصنّعة تقيّد عمل المنبهات عند فرض إيقاف التطبيق أو تفعيل توفير البطارية.
- بيانات المسبحة والإعدادات محلية على نفس الجهاز.
- هذه النسخة الأولية تحتاج اختباراً على جهاز فعلي، خصوصاً سلوك التنبيه على إصدارات Android المختلفة، قبل نشرها إنتاجياً.
