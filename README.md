# رِفاء — متجر مياه الشرب والتوصيل

واجهة متجر عربية RTL قابلة للنشر على GitHub Pages، مناسبة للجوال والكمبيوتر.

## التشغيل
1. فك ضغط الملف.
2. ارفع محتويات المجلد إلى مستودع GitHub.
3. من Settings → Pages اختر النشر من الفرع `main` والمجلد `/ (root)`.
4. افتح رابط GitHub Pages.

## ما تتضمنه النسخة
- عرض منتجات مياه تجريبية وفئات.
- سلة مشتريات وتعديل الكميات.
- نموذج طلب للمنزل أو المحل.
- سجل طلبات وتفاصيلها.
- حفظ البيانات محلياً في IndexedDB على نفس الجهاز.
- ملف PWA وإمكانية التثبيت ودعم العمل دون اتصال بعد أول زيارة.
- لوحة إدارة محلية لإضافة المنتجات وتحديث حالات الطلبات وتصدير CSV.

## مهم قبل الإطلاق التجاري
هذه نسخة أولية قابلة للتشغيل والمعاينة وليست نظام تشغيل تجارياً متعدد المستخدمين. الطلبات والمنتجات تحفظ في متصفح الجهاز فقط، ولا تصل تلقائياً إلى موظفي الشركة أو السائقين. لا توجد بوابة دفع إلكترونية أو تتبع مباشر للسائق في هذه النسخة.

لتحويلها إلى نظام إنتاج حقيقي، يلزم:
- قاعدة بيانات سحابية (مثل Supabase أو Firebase) وربط صلاحيات آمن.
- نظام دخول للعملاء والموظفين والسائقين.
- واجهة API آمنة لإنشاء الطلبات وإدارة المخزون والحالات.
- بوابة دفع مرخصة ومفاتيحها السرية محفوظة على الخادم.
- تحديد نطاق التوصيل ورسومه، وربط الخرائط/الموقع بموافقة العميل.
- رقم واتساب/هاتف الشركة وسياسة الخصوصية والشروط.
- اعتماد أسماء المنتجات والأسعار والصور الرسمية من شركة رِفاء.

## تخصيص الأسعار
الأسعار المعروضة افتراضية لغرض تجربة الواجهة. يمكن تعديلها من لوحة الإدارة في المتصفح، أو تعديل مصفوفة `seedProducts` داخل `index.html`.

## الملفات
- `index.html`: التطبيق.
- `manifest.webmanifest`: إعدادات التثبيت.
- `sw.js`: التخزين المؤقت والعمل دون اتصال.
- `assets/icon.svg`: أيقونة أولية.
