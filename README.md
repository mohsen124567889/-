# المُصلّي — AlMusalli

مشروع أولي قابل للبناء لتطبيق مواقيت الصلاة، يتضمن:
- واجهة عربية RTL متجاوبة تعمل على GitHub Pages.
- مواقيت الصلاة من AlAdhan API (طريقة أم القرى، method=4) مع تخزين آخر مواقيت تم جلبها.
- إعدادات تشغيل تنبيه لكل صلاة.
- تطبيق Android أصلي مبني بـ Kotlin وWebView.
- جدولة محلية عبر AlarmManager، وإشعار عالي الأولوية مع Full-screen intent لواجهة تنبيه تشبه المكالمة.
- إعادة جدولة التنبيهات بعد إعادة تشغيل الجهاز أو تغيير الوقت/المنطقة الزمنية.
- GitHub Actions لبناء APK تلقائياً.

## رفع نسخة الويب على GitHub Pages
1. أنشئ مستودع GitHub جديداً.
2. ارفع محتويات هذا المجلد إلى جذر المستودع.
3. افتح Settings → Pages.
4. اختر Deploy from a branch ثم `main` و`/ (root)` ثم Save.
5. افتح رابط GitHub Pages وثبّت الموقع من قائمة المتصفح إذا رغبت.

## بناء APK عبر GitHub Actions
1. ارفع المشروع كاملاً إلى GitHub.
2. افتح تبويب Actions.
3. شغّل workflow باسم **Build Android APK** (أو انتظر تشغيله بعد push).
4. افتح تشغيل workflow الناجح، ثم نزّل artifact باسم `musalli-debug-apk`.
5. ثبّت APK على هاتف Android بعد السماح بالتثبيت من المصدر الذي نزّلت منه.

## اختبار البناء محلياً
يتطلب JDK 17 وAndroid SDK وGradle 8.9 أو أحدث متوافقاً مع Android Gradle Plugin 8.7.3:

```bash
gradle assembleDebug
```

ملف APK الناتج: `app/build/outputs/apk/debug/app-debug.apk`.

## إعداد التنبيهات على أندرويد
- اسمح بإشعارات التطبيق.
- اسمح بالمنبهات والتذكيرات الدقيقة (Alarms & reminders) عند طلب النظام.
- اسمح بإشعارات ملء الشاشة إذا ظهر خيارها في إعدادات التطبيق على إصدار أندرويد لديك.
- بعض الشركات المصنّعة تقيّد عمل التطبيقات في الخلفية؛ قد تحتاج إلى استثناء التطبيق من تحسين البطارية.

## حدود النسخة الحالية
- مواقيت الصلاة تُجلب من الإنترنت من AlAdhan API، مع استخدام آخر مواقيت محفوظة عند انقطاع الاتصال. يجب مراجعة طريقة الحساب وإعدادات الموقع مع تقويم الجهة الرسمية المحلية.
- نسخة الويب على GitHub لا تستطيع ضمان تنبيه دقيق بعد إغلاق المتصفح؛ التنبيهات الخلفية وشاشة التنبيه المتقدمة مخصصة لنسخة Android.
- شاشة التنبيه الكاملة تعتمد على صلاحيات النظام وسياسات Android، وقد يعرض بعض الأجهزة إشعاراً عادياً بدلاً منها.
- الواجهة الحالية أساس عملي للإصدار الأول؛ المصحف الكامل، الصوتيات، التفسير، القبلة، والتقويم الموسع مراحل تطوير لاحقة وليست مضمّنة بعد.

## الخصوصية
لا يوجد تسجيل دخول أو خادم خاص أو تتبع مستخدم في هذه النسخة. تُحفظ إعدادات المدينة والعداد والمواقيت على الجهاز. يجري طلب مواقيت الصلاة من AlAdhan API عند التحديث.
