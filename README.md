# المُصلّي — Android + GitHub Pages

مشروع بداية قابل للبناء عبر GitHub Actions، ويحتوي تطبيق Android أصلياً يعرض واجهة محلية داخل WebView.

## رفع المشروع
1. فك ضغط الملف.
2. ارفع **محتويات** المجلد إلى المستودع الحالي `mohsen124567889/-` (وليس مجلد ZIP نفسه).
3. من تبويب **Actions** شغّل workflow باسم **Build Android APK** أو ادفع commit جديداً.
4. بعد نجاح البناء افتح نتيجة التشغيل ثم **Artifacts** ونزّل `AlMusalli-debug-apk`.

## ملاحظات مهمة
- هذا الإصدار يصلح أساس البناء ويعالج سبب الخطأ السابق: لا يعتمد على `gradlew` المفقود، بل يثبت Gradle داخل GitHub Actions.
- ملف APK الناتج نسخة Debug للتجربة.
- الواجهة الحالية نموذج أولي محلي. لا تدّعي هذه النسخة بعدُ حساب مواقيت الصلاة حسب الموقع أو إطلاق منبّه موثوق في الخلفية أو شاشة مكالمة نظامية. هذه تحتاج استكمال تكامل مواقيت الصلاة وصلاحيات Android (التنبيهات والمنبهات الدقيقة وشاشة ملء الشاشة) واختبارها على الجهاز.
- تنبيهات المتصفح/PWA وحدها لا تضمن العمل بعد إغلاق المتصفح.
