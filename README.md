# رِفاء — نظام بيع وتوصيل المياه (نسخة محلية)

## التشغيل
1. فك ضغط الملف.
2. افتح `index.html` في المتصفح، أو ارفع المجلد إلى GitHub Pages / أي استضافة مواقع ثابتة.
3. من القائمة أعلى الصفحة بدّل بين واجهة العميل والإدارة والسائق.

## ما يعمل في هذه النسخة
- عرض المنتجات وإضافتها إلى السلة وتعديل الكميات.
- إنشاء طلب مع الاسم ورقم الجوال والعنوان وملاحظات.
- إدارة المنتجات والأسعار والمخزون.
- متابعة الطلبات وتغيير حالتها.
- واجهة السائق وعرض بيانات التوصيل والاتصال بالعميل وتحديث الطلب إلى تم التسليم.
- تخزين محلي عبر `localStorage`، وتصدير/استيراد نسخة احتياطية JSON.
- ملف PWA وService Worker للتخزين المؤقت عند الاستضافة عبر HTTPS.

## حدود النسخة المحلية
- البيانات موجودة في متصفح/جهاز واحد فقط. تبديل الدور لا ينشئ حسابات مستقلة ولا يشارك البيانات مع أجهزة أخرى.
- لا يوجد خادم أو قاعدة بيانات سحابية أو تسجيل دخول آمن.
- لا يوجد دفع إلكتروني أو رسائل SMS/واتساب أو تتبع GPS أو إشعارات خلفية.
- لا تستخدمها لتخزين بيانات عملاء حقيقية أو حساسة على جهاز مشترك قبل إضافة خادم ومراجعة أمنية.

## ملفات المشروع
- `index.html`: التطبيق كامل (HTML/CSS/JavaScript).
- `manifest.webmanifest`: تعريف التطبيق القابل للتثبيت.
- `sw.js`: التخزين المؤقت الأساسي.
